FSE x[2,4,6,8,10,12,16] × y[1,2,4] microbench, min of 5 batches × 1000 iters/batch per cell
(numbers are MB/s; higher = faster.  x2y2 = FSE's shipping decode shape.)
size = source-byte count.  pmaj = P(bit = 0) = major-symbol probability (each bit drawn IID).
high pmaj = more zeros = skewed bitmap = tighter FSE compression.
Per-call cost model:
  FSE columns - steady-state (pre-built DTable).  Matches
                ph's real usage: 12 static tables picked
                at runtime by 1-byte table-id from the wire.
  su_ns       - FSE per-call setup cost in ns (FSE_readNCount
                + FSE_buildDTable).  Add to derive 'FSE full
                per-call' MB/s for any x*y as:
                bytes / (su_ns + bytes * 1000/steady_mbps).
  huf0 columns - FULL per-call (HUF_decompress*X*_DCtx_wksp:
                 reads table header + builds DTable + decodes).
                 Matches what zstd does at runtime per call.
  Oodle column - FULL per-call (newlz_get_array_huff:
                 reads table header + builds tab + decodes).
                 No _usingDTable variant in Oodle's public API.
                 Tuner picks huff6 (6-stream).  ASM kernels
                 wired in via OodleUE patches in
                 extras/oodle_build_patches/.
